# Tarefa: Correção Cirúrgica do Esfera_Nativo

## Contexto REAL do Código

Este é um cliente desktop Win32 C++ com renderização Direct2D customizada. A interface tem 3 bugs:

### BUG 1: Botões Fantasmas
O main.cpp cria controles Win32 (CreateWindowEx) com posições que NÃO batem com o layout D2D.

**O que existe no main.cpp:**
- Constantes: SIDEBAR_W = 210.0f, HEADER_H = 60.0f
- Controles Win32 são criados em `CreateMainUIControls()` com coordenadas fixas
- A função `RepositionControls()` já existe e usa SIDEBAR_W + 24.0f como contentX
- O UIManager tem um método `RenderDevicesTab()` que renderiza cards de dispositivos com D2D
- Os controles Win32 (edit boxes, botões) ficam SOBRE o D2D

**O que o UIManager faz (NÃO MEXER):**
- Render() → RenderSidebar() + RenderHeader() + tab content
- RenderDevicesTab() → desenha cards com D2D (posições: contentX = sidebarWidth + 24, y = headerHeight + 12)
- HandleMouseMove/HandleClick → hit testing em 22+ ações (DEVICE_CONNECT_ACTION, DEVICE_REBOOT, etc.)
- BuildUITree() → monta a árvore de componentes D2DUI
- 18 brushes D2D, sistema de partículas, sistema de logs

**Problema específico:**
- O DrawDeviceCard renderiza o card D2D em (cx, cyDev) = (contentX, headerHeight + 12)
- O card tem: label "IP:Port" em (cx+12, cyDev+12), botões de ação em (cx+16, cyDev+80)
- Os controles Win32 (edit IP, botão Conectar) devem ficar DENTRO do card D2D
- Se as posições não batem, os controles ficam flutuando em lugar errado

### BUG 2: Dashboard com Dados Aleatórios
O DashboardViewModel já foi corrigido para usar SQLite + AdbConnector (não mais rand()). Isso já está funcionando.

### BUG 3: Logs Visíveis ao Cliente
O UIManager tem um sistema de logs com `m_logEntries` (deque de LogEntry com severity DEBUG/INFO/WARN/ERR). A aba de logs já filtra `DEBUG` quando `m_logShowDebug` é falso. Isso já foi corrigido.

### BUG 4 (NOVO): Security Bypass
Quando `g_sessionContext` é nulo (antes do login), o DrawDeviceCard mostra TODOS os 6 botões de admin no `else`. Já foi corrigido para `if (!g_sessionContext) { /* no buttons */ }`.
